## 规则

第一轮没改：`critical_identity_compatible`、`MIN_MATCH=0.86`、`MIN_GAP=0.045`、`MIN_FEATURES=18`。原先 exact-trim 能中的车仍走这一轮。

两轮（当年主目录、历史 vault）都失败后，才用身份回退，候选池是同年主目录 + 同年 vault + 之家年款参配目录。

回退里改了这些：

- 档位残差忽略营销词和代际套话（蓝鲸NE、第N代、改款层级、国VI/国V、驱动、座位数、续航、电池）。「型」和「版」视为同一个字，Pro、+ 仍保留，所以悦享版Pro 不是悦享版，领航版+ 不是领航版。
- 允许的前缀只有「国潮版 / 经典 / 北京」以及纯字母数字（T-ROC、KX3、RS）。豪华这类中文前缀不能借后缀贴到更低档。RS 拓界版不会压过拓界版。
- 动力只认标题里的排量或徽章（含 TGDI、TCI、GDIT、DVVT、TSI、TFSI）。1.8TD≡1.8T、2.0TD≡2.0T，日产 1.6L XE≡1.6XE。不把 20T、230TSI、280TSI、535T、270T、18T 全局换成升数。两边徽章集合不同就不挂，例如 290TGDI≠1.5TCI、1.5GDIT≠1.5T、18T≠15T。发动机行里的「1.5T 169马力」不能盖过标题里的 1.5GDIT。
- 变速箱：自动可以对应 DCT、DSG、CVT、手自一体；DCT 与 DSG 视为同一类。手动和自动冲突。这是为了消掉「DCT 写成自动」的误伤。
- 改款 / 改款二 / 改款三 层级不同不挂。候选写了第N代而标题不是这一代，也不挂。标题有第二代、候选没写第N代时，不因此否决。
- 哈弗H6 且标题是第二代（不是第三代）时，若筛完动力后只剩一条国潮版，挂国潮版。其他车系不做这个替换。
- 轴距只在同一档位仍有多条、彼此相差至少 40mm、且回填轴距落在其中一条 15mm 内时做决胜。不因为回填轴距和标题不一致就否决唯一档位。
- 秦PLUS DM 的年款目录用 series 5964（秦PLUS），唐DM 用 3430（唐新能源）。只影响回退抓目录，不改第一轮车系匹配。
- 读坏的 vault 202602–202606 跳过，并记住这个月是空的，避免每辆车重复解包。

新 spec 仍走原来的 live 参配页抓取。配置行少于 20 或可核验特征少于 18 的不写入已核验配置。途铠 48880 第一次超时，重试成功后通过了这道门。
